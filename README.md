The code made available here assumes that [GroundingDINO](https://github.com/idea-research/groundingdino), [SAM](https://github.com/facebookresearch/segment-anything), and [OrganoID](https://github.com/jono-m/OrganoID) are all installed on your device, according to their own instructions, though most functions should work without GroundingDINO. It also assumes that the device running the software has at least one graphics card and that the files provided here have been copied into the OrganoID directory, though they can be made to work in another directory by modifying the import statements.
